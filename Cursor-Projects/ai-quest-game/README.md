# AI Quest — Learn to Use AI (Ages 12–15)

A short, mission-based game that teaches 12–15 year olds how to use AI tools well. It uses **real-world examples** from **Claude** and **ChatGPT** so players learn strategies they can use right away.

## What players learn

- **What AI is good (and not good) for** — e.g. explaining, brainstorming, step-by-step help vs. knowing your class rules or doing your thinking for you.
- **Prompt power** — why being specific (audience, format, goal) gets better answers, with a real “explain like I’m 12” style prompt.
- **Claude** — Learning Mode (Socratic-style questions), Artifacts (quizzes, materials), and turning notes into clean documents.
- **ChatGPT** — study prompts, step-by-step math, exam-style practice questions with grading and explanations.
- **Using AI responsibly** — support your own thinking and writing instead of copying or submitting AI text as yours.

## How to run the game

No server or install needed. Use any of these:

1. **Double-click** `index.html` to open it in your browser.
2. **From terminal** (macOS):  
   `open index.html`
3. **Simple local server** (optional):  
   `python3 -m http.server 8000`  
   Then open: `http://localhost:8000`

## Structure

- **Mission 1** — Good vs bad uses of AI for school.
- **Mission 2** — Vague vs specific prompts (with a real ChatGPT-style “explain like 12 + example + analogy” prompt).
- **Mission 3** — Claude Learning Mode & Artifacts; ChatGPT study and homework prompts.
- **Mission 4** — When and how to use AI (e.g. brainstorm + your own essay).
- **Mission 5** — Pick the best “practice for my math test” prompt (real exam-practice style).
- **Results** — Score and a short recap.

All content is in one file: `index.html` (HTML, CSS, and JavaScript). No build step or dependencies.
